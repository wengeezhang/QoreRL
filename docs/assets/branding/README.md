## Generation prompts

Reference for both final assets: the bottom-right **F / LAYERED CORE** candidate in `qorerl-logo-candidates.png`.

### Horizontal lockup

> Use case: logo-brand. Produce a single polished horizontal logo lockup for QoreRL based on SELECTED F / LAYERED CORE, bottom-right candidate in the reference sheet. Only reproduce F, no other candidates. Pure solid white background. Exact angular Q symbol of F: bright cyan upper hexagon roof and right arm; darker teal lower-left hexagon base and diagonal tail; clear diagonal white separating gaps. Smooth flat solid-color geometry with crisp edges, no noise, no speckles, no texture, no shadows. To its right, the exact dark-navy bold wordmark 'QoreRL', matching F's typography. Below the wordmark exact tagline 'Low precision, more control.' in smaller dark-navy type. Single logo centered with generous 10% margins on a wide landscape 3:1 canvas. Icon and wordmark together should occupy 80% width. No F label, no headings, no grid, no extraneous annotations. This will be the official GitHub README header.

### Square mark

> Use case: logo-brand. Extract only the SELECTED F / LAYERED CORE geometric Q icon, bottom-right on reference contact sheet. Produce clean square icon on pure white background. NO WORDS, NO TEXT, NO LABELS. Center icon occupying 76% of square. Faithfully keep F's angular open hexagonal Q shape: cyan upper roof plus right vertical arm; darker teal lower-left bracket plus bottom and lower-right diagonal Q tail; white diagonal gaps dividing the layers. Flat solid fills, crisp smooth geometric edges, no texture, noise, shadow, speckles or decorations. A professional brand mark for a developer tool.
